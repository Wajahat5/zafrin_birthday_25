# Happy Birthday — Zafrin (React + Vite)

This project is a complete skeleton for a single-page interactive birthday website built with React, Vite, TailwindCSS, Framer Motion and Howler.js for audio.

## What is included
- App structure with landing, flip-cards, timeline, balloons, letter, photo reel and final cake sections.
- Placeholder image boxes and instructions to add your own assets in `/public/assets/`.
- `package.json` with dependencies (Framer Motion, Howler, Tailwind, Vite).
- Tailwind and PostCSS configs.

## How to run locally
1. Install Node.js (v18+ recommended).
2. In the project folder, run:
```bash
npm install
npm run dev
```
3. Open the dev URL (usually http://localhost:5173).

## Notes
- Mobile browsers block autoplay so background music will only start after user interaction (the play button).
- Replace the audio placeholders in `/public/assets/` with your desired mp3 files (names: chime.mp3, pop.mp3, whoosh.mp3, piano_loop.mp3).
- Replace image placeholders by adding images in `/public/assets/images/` and swapping the src in components if desired.
